# 賭場戰爭 (DCZZ)

程式碼增加單元測試

最後寫入PerGameLog的值對照

| Name    | Parameter    |
|:-------:|:------------:|
| 有效注   | BetAmount    |
| 返還     | PayoutAmount |
| 稅      | TaxAmount    |
| 流水     | ValidAmount  |
| 更新金幣 | UpdateAmount  |

> 流水：輸的絕對值

> PayoutAmount：是返還金額加稅

## 玩家輸
```
// 自動底注: 1.00
// 手動底注: 100.00
// 手動和牌: 10.00
// 階段一: 輸
//   有效注: 101.00[底] + 10.00[和] = 111.00
//   返還: 0.00
//   稅: 0.00
//   流水: 111.00
// 階段二: 無
// 總:
//   有效注: 111.00[階段一]
//   返還: 0.00
//   稅: 0.00
//   流水: 111.00[階段一]
//   更新金幣: 0.00 - 111.00 = -111.00
```

//   稅:  0.00
//   流水: 50.50

//   有效注: 10.00[階段一] + 101.00[階段二] = 111.00
//   返還: 105.00[階段一] + 50.50[階段二] = 155.50
