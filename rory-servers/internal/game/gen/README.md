# 將軍 (GEN)


### `3松` 解除RT
只要是透過 3松連線 這個 Result 解除的，下次Mode一定要是天國(C)

### 1G連
1G連，後稱作連莊，在Bonus中，達成下述條件，即可在Bonus Game結束後，第一轉開出Bonus確定。

* 單7連線，可連莊1次 (PayTable 達成)
* 雙7連線，可連莊2次 (PayTable 達成)
* 純槓龜，可連莊3次 (PayTable 達成)
* JAC槓龜，可連莊1次 (PayTable 達成)
* JAC中，連續8次銅鐘連線，可連莊1次 (Before Init，檢查)
* BIG BONUS中 觸發JAC IN 0次，可連莊3次 (Before Init，檢查)
* BIG BONUS中 觸發JAC IN 1次，可連莊2次 (Before Init，檢查)
* BIG BONUS中 觸發JAC IN 2次，可連莊3次 (Before Init，檢查)

### 機會模式
可與 A, B, C 模式重複存在的一種狀態，在機會模式下，重新決定模式時，固定為天國(C)
> 給Client，模式＋剩餘次數

開啟的條件
* 在(A/B/C)模式下
* 當前轉數在某個區間中
* 轉到 replay 連線
* 以 1/256 的機率骰出
* 在 Bonus 下不會觸發

關閉條件
* 到達可維持回合數
* 實際Assign模式為天國後(完成任務)
